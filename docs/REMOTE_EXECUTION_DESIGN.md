# 远程执行架构与扩展边界

运维命令见 [远程执行指南](REMOTE_EXECUTION.md)，后续业务接线顺序见 [实施计划 R2–R6](IMPLEMENTATION_PLAN.md#第三批完整远程执行-r2r6)。

## 唯一数据源与当前范围

VPS 保留唯一书库数据库、归档、认证、阅读服务和业务调度。InstaBox 只取得任务级输入并交付产物；云端可丢弃缓存不是备份，不能把云端 SQLite 同步覆盖回 VPS。

当前协议注册诊断、EPUB、Pixiv 单本/固定 API、AI 文本，以及可选的单站签到状态/提交。Pixiv 与 AI 使用受限上游转发：密钥留在 VPS，worker 不接受任意 URL/SQL/代码，不持有书库。默认公网出口在 VPS；可选 HTTPS CONNECT 服务可迁移远程请求出口，保留上游端到端 TLS，独立校验出口密钥、证书及公网主机白名单。原业务 cron、登录与附件下载仍在 VPS；阅读进度独立运行。可选出口未通过生产部署验收。

## 进程和凭据

- Web 持有书库权限及 worker bootstrap 摘要，提供受认证的提交/查询/下载和 worker RPC。
- controller 持有指定机器的 InstaBox key 与控制库访问权限，不持有 worker bootstrap 明文。
- worker 持有独立 bootstrap，执行固定处理器，不持有书库数据库、Dashboard/Flask/AI secret 或上游通用 API key/token/Cookie。可选签到 profile 是明确配置的 worker 本地状态，不能与另一台机器同时运行。
- CLI 只读显式环境，不搜索业务 `.env`；默认关闭。执行 payload 不允许任意 shell、Python、SQL、URL 或路径。

控制库与业务库分离。session secret 只存摘要；冷启动创建新 boot 身份，旧 session/epoch/fence 不能重新取得发布权。当前 epoch 的退役 boot 墓碑不能被普通 GC 清掉。

## 提交、领取和发布

提交冻结版本化输入清单并按 Idempotency-Key 去重。上限为 20 个未终结 run；手动提交一小时后过期，每 attempt 十分钟，纯计算任务最多三次。客户端重试不得换成更新后的小说内容。

单机器单槽，领取必须验证 gate、worker readiness、运行预算、磁盘配额和任务状态。run、attempt、session、epoch、fence 与 input digest 一起限定权限；过期 lease 只允许新 attempt，不恢复旧 owner。

心跳租约 180 秒，worker 每 30 秒续租；最后有效确认对应的首次发送后 120 秒停止执行。迟到响应、重发相同 seq、平台暂停恢复不能延长这一预算。

上传只是暂存，数据库持久化发布回执才是成功。上传或发布响应丢失先查回执，不先重算；传输、大小、digest、EPUB 内容语义和身份都需校验。取消、失去租约和旧 attempt 的迟到产物不能落为成功。

## 云机生命周期

controller 把启动/暂停意图和幂等键持久化，202 后继续检查 operation、runtime 与新鲜 worker session。平台 running 不代表任务成功或可派发。

真实排队需求才唤醒暂停机器；人工 hold 不唤醒停机实例。空闲五分钟后先关闭派发，再核对新任务、hold、上传和实例归属，只有能证明由本控制器激活的会话才自动暂停。

暂停请求已经发出时新任务不能撤回平台请求，必须等 operation 收敛再恢复。未知结果、认证拒绝和额度拒绝保留状态供人工核对，禁止无限重试；不轮换机器规避冷却。

## 文件、维护与恢复

VPS blobs 1 GiB 配额包含预留，worker 专用目录上限 128 MiB。路径必须位于显式专用根，拒绝符号链接/路径逃逸，不清理操作员任意目录。

终态输入/产物保留 24 小时，元数据 14 天；孤儿/未知临时文件至少一小时。GC 采用事务标记 deleting、删除已核验文件、事务确认的可重入流程，deleting 对象不能获得新引用；活动任务/上传、有效凭据和结果回执保护不能被定时调度绕过。

恢复旧控制库前关闭 API 和 controller，核对 provider 在途 operation，显式离线旋转 epoch、撤销旧 session/attempt 并关闭 gate。恢复不会自动取得云实例归属；必须重新核对后才能重新派发。普通重启不旋转 epoch。

备份必须包含业务数据库一致快照、归档、控制库/必要产物、配置与解密密钥，并有独立恢复验证。禁止在线复制正在写入的 DB/WAL/SHM 作为完整备份。

## 扩展验收

业务账户租约由 VPS 续期，worker 请求不能延长账户所有权；本地/远程共用间隔与退避。上游调用先写 sent 回执，重复轮询只读结果；进程中断的 sent 变为结果未知，不重发。AI 发送前调用原预算 guard；失联、取消、配置或来源失效终止授权。模型正文输入及临时回执加密，任务密钥不落持久队列。签到提交按站点/账号代号/业务日持久去重；未知结果只查询状态，不能通过新 run 绕过台账。

新增任务必须同时修改严格契约、数据库 kind 约束、worker 固定分派、VPS 接收和测试，禁止只加 UI 开关。需要远端账号的业务先完成任务范围凭据、共享限流与本地/云端账户互斥，再接现有任务/水位/取消语义。

默认测试只使用临时库、合成 EPUB、fake 平台与本地传输，验证并发、重放、租约、崩溃和恢复。完整 VM 冷启动、平台强制暂停/冷却、真实私有输入和生产回退不能由本地通过推断。
