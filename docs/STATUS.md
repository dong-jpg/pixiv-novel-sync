## 分支与运行边界

| 分支 | 范围 | 维护方式 |
| --- | --- | --- |
| main | 同步、归档、救援、阅读、推荐、作品分析、偏好学习、远程执行基础与共享 AI | 共享修复先进入 main |
| ai-writing | main 全部功能，加创作项目、章节、向导、蒸馏、检索与润色 | merge main，写作不反向合入 main |

代码交付与实际部署分开。最新留存生产版本信息为 2026-11-13 的 `4b8133e`，不是本轮重新核验的在线 HEAD。当前开发未更新生产服务、唤醒云实例或调用付费模型。
