## 远程方案退役与迁移

移除整个远程控制/执行包、独立 CLI、worker API、远程管理页、云出口、签到适配以及配套 systemd / Nginx 配置。同步、推荐和 AI Provider 不再创建远程 run 或查询云机状态。单本抓取保留本地规范化与验证，删除专供远程传输的协议封装。

旧 YAML 和环境变量可保留用于迁移，但不再影响执行位置。保存同步设置会移除 `pixiv_execution`。书库业务表、AI 预算、来源版本和检查点保留；旧远程控制库不再使用，未完成远程队列不会自动重放。以前冻结在远程 AI 模式下的分析需按配置变化重新预览确认。

源码变更没有停止线上旧服务、删除云实例或迁移生产数据。停用旧 Web、timer、controller、worker 及一致备份的步骤见 [Docker 指南](DOCKER.md)，必须在 NAS 自动同步启用前完成。
