# 项目现状

更新：2026-11-25。当前代码改为本地执行，NAS / Docker 的实际部署与代码验证分开记录。

## 分支与运行边界

| 分支 | 范围 | 交付边界 |
| --- | --- | --- |
| main | 同步、归档、救援、阅读、推荐、作品分析、偏好学习及共享 AI | 本次修改位于 main 工作区 |
| ai-writing | 继承书库能力，并增加写作、向导及成人润色 | 本次未合并或验证该分支 |

Web 使用单进程 Flask + Waitress，SQLite 保存业务状态，现有调度器串行执行同步任务。NAS 容器承载同一程序，不能通过多个实例共享书库来横向扩容。模型调用仍访问所配置的 Provider，NAS 不承担模型推理。

## 远程方案退役与迁移

移除整个远程控制/执行包、独立 CLI、worker API、远程管理页、云出口、签到适配以及配套 systemd / Nginx 配置。同步、推荐和 AI Provider 不再创建远程 run 或查询云机状态。单本抓取保留本地规范化与验证，删除专供远程传输的协议封装。

旧 YAML 和环境变量可保留用于迁移，但不再影响执行位置。保存同步设置会移除 `pixiv_execution`。书库业务表、AI 预算、来源版本和检查点保留；旧远程控制库不再使用，未完成远程队列不会自动重放。以前冻结在远程 AI 模式下的分析需按配置变化重新预览确认。

源码变更没有停止线上旧服务、删除云实例或迁移生产数据。停用旧 Web、timer、controller、worker 及一致备份的步骤见 [Docker 指南](DOCKER.md)，必须在 NAS 自动同步启用前完成。

## 已有修复与质量边界

- 归档删除拒绝书库根及其祖先；下载取消保留旧文件，缺失附件会补齐；同数量换章可识别。
- X1 结论纠错使依赖画像失效；A1 单元读取和 A2 来源 revision 减少重复正文/报告读取，保留发送前及发布前校验。
- S1 完整系列目录、收藏游标回扫和当前统计原子重算保留明确读后评价；默认七天回扫不提高请求频率。
- 本地 Vue、样式、启动失败提示与访客入口随安装包交付；手机 Firefox `error_net_timeout` 的具体网络根因尚未定位，不能以桌面窄屏通过替代真机验收。
- 保留工作区已有的推荐“部分完成”修复：内部查询/候选错误投影到外层任务状态，可用推荐结果继续保留。
- 旧环境长任务约一小时后出现连续 unknown 的原因仍需核对 Pixiv 鉴权及网络响应；恢复本地执行不等于证明该独立问题已解决。
- 真实单篇 AI 分析曾在原预算内校验失败并暂停；短生成通过不能代替全文报告、个人画像或全库策略的质量验收，也不允许因此扩大预算。
