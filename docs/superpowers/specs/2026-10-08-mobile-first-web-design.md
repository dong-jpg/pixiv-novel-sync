# 移动优先书库与安全持久登录设计

**确认：** 用户已确认“移动优先、桌面兼容，可选记住登录30天”的范围，并明确要求开始实施。主要设备是安卓 Chromium 浏览器；先覆盖线上 main，不恢复写作/成人模块。本文件将已确认的方案具体化，不再次中断实施索取重复确认。记住选项默认不勾选，具体期限见下文。

## 目标与边界

- 登录、推荐、阅读和日常管理可在 360/390/430px 手机竖屏使用，兼容横屏、放大字体和桌面。
- 保留 Flask/Jinja + Vue 3 + Library OS，不新增独立手机站、PWA、账户注册体系或新认证服务。
- 仅在本地隔离分支开发与验证；本轮不修改服务器配置/数据库，不推送或部署。
- 现有服务器/TLS报告等未提交文档必须保留，不能混入任务提交或被覆盖。

## 1. 安全登录

登录页从 Python 内联 HTML 移至独立 `login.html`，不加载受保护导航、推荐 API 或重型前端框架。使用 viewport、可缩放页面、至少48px登录控件、16px输入字体、可见标签和页内错误提示；适配安卓软键盘及安全区。

提供用户可选的“在此设备保持登录30天”，默认不勾选。未勾选保持浏览器会话 Cookie，服务端最长7天；勾选后 Cookie 持久保存，服务端固定30天到期，普通访问不得不断延长期限。清除站点数据、无痕模式或换浏览器仍需登录。

使用既有签名、HttpOnly、SameSite=Lax 会话 Cookie 携带随机会话标识；数据库只存随机标识的 SHA-256 摘要、口令版本 HMAC、签发/过期时间和持久标记，不保存访问口令或随机标识原文。新增会话表不改旧业务表。口令版本 HMAC 使用服务端 Flask secret，与可见口令摘要区分，避免离线猜测弱口令。

- 登录成功重新生成标识，撤销当前浏览器此前标识，避免会话固定。
- 主动退出撤销服务端记录；旧 Cookie 重放失效，其他设备不被无故退出。
- 生效中的访问口令改变后，旧会话版本不匹配并失效。服务端重启但 secret/数据库不变时，未过期会话继续有效。
- 旧版无服务端标识的登录 Cookie 需重新登录一次；不提供永久兼容绕过。
- 验证存储临时不可用时拒绝受保护请求并返回503，但不清除有效 Cookie，让用户恢复后可重试。
- 保持登录限流、常量时间口令比较、CSRF、救援 API 独立认证、本机无口令安全边界。
- HTTPS 上线前必须显式确认 `PIXIV_COOKIE_SECURE=1` 或既有可信 HTTPS 代理配置；不为测试关闭生产安全选项。开发用隔离假数据/显式本机配置。

## 2. 推荐与首页

首页保留统计和任务控制，但手机上缩减它们的首屏占用，优先呈现推荐。首页和偏好页复用同一推荐卡片：标题至少两行可读、理由可展开、标签受控换行、状态/分数字号不挤占标题。

卡片本体不包裹所有交互的外链；作品链接与反馈按钮分离，防止点反馈误跳 Pixiv。交互至少44px，反馈请求中防重复点击，失败明确显示且不伪装成功。

“隐藏已反馈”改用后端已有 `status` 过滤，与页码、总页数同步；过滤/切页请求使用代次保护，迟到响应不得覆盖新选择。反馈后当前页变空时回到仍存在的最后一页。保留旧不带 page 的数组接口兼容。

偏好页将“推荐结果”和“画像/搜索设置”分区，默认先看推荐，管理信息不挡在结果前；不修改推荐算法、反馈枚举或现有数据。

## 3. 共享导航与控件

手机底栏为：首页、书库、作者与系列、任务、更多。更多收纳偏好/待确认/设置/退出等入口，保留当前路径高亮、所有现存功能与桌面侧栏，不增加拥挤的第七个底栏项。

主要触控目标至少44px；表单输入16px、限宽可收缩；安全区与底栏留白匹配。分页可操作，不靠去掉最小高度换密度。保留必要宽表的局部横滚，不放任整页溢出。

通用弹窗支持键盘焦点、关闭后恢复焦点、背景滚动锁与可选的遮罩关闭策略。手机内容/底部按钮能在有限高度内滚动或换行；一次性 Token 弹窗关闭遮罩误触。

## 4. 阅读与返回上下文

手机阅读页使用独立工具条，不叠加两条底栏。保存阅读进度、字号/章节导航可在当前位置使用；重置、移除收藏、删除归档收进明确的次级菜单，保留确认与失败保护。

显式携带站内返回上下文，不依赖已被 no-referrer 禁止的 referrer。禁止协议相对 URL、外域、反斜杠及控制字符；列表筛选、页码与滚动位置可恢复。保留原有进度恢复/保存竞态防护，迟到恢复不能覆盖用户手动滚动。

救援来源提供触屏可展开明细，不只靠悬停 title。桌面保持原有阅读和管理能力。

## 5. 管理页面

- 待删除接口的HTTP错误与真实空态区分，原地重试保留上下文，不触发检测任务。
- 模型/模型池编辑定位到正确表单并聚焦；错误在操作区域可见且不自动消失。
- Agent长选项与刷新按钮在窄屏不撑宽整页。
- 一次性Token复制成功/失败在弹窗内可见，提供手动复制；明确关闭后清空，不保存明文。

## 6. 共用实现接口

共享基础任务提供 `base.html` 的 `body_class` block，以及在全局组件注册后、挂载前执行的可选 `window.registerPageComponents(app)`。推荐页通过新组件 partial 安装该钩子。

`app-modal` 新增 `closeOnBackdrop` Boolean prop，默认 true；Token弹窗使用 `:close-on-backdrop="false"`。

阅读页使用 `body_class` 值 `pns-reader-page`。在手机断点下隐藏全站底栏，阅读任务自身提供工具条及对应安全区留白。

阅读/返回辅助代码放在独立 `navigation_helpers.html` partial，由需要的页面在自己的 `extra_scripts` 引入，避免并行修改共享 base。对外函数至少包括 `window.safeDashboardReturn(value, fallback)`、`window.withDashboardReturn(target, from)` 和用于列表滚动恢复的显式生命周期接口；具体恢复器必须可取消、仅恢复一次。
