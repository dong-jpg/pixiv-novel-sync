# 作品分析与偏好学习设计

本文描述已归档单篇/系列的内容报告、个人偏好 / XP 画像与全库分析之间的契约。操作见 [偏好学习指南](PREFERENCE_LEARNING_GUIDE.md)，接口见 [API 契约](frontend-api-contract.md#work-analysis-apis)，尚未完成的工作见 [实施计划](IMPLEMENTATION_PLAN.md)。

## 三种独立含义

1. **作品报告**回答作品写了什么、有哪些特征、依据在哪里，不把作品内容当成用户身份或喜好。
2. **读后评价**由用户明确表达 liked/disliked/neutral，支持撤回；收藏、已读、追更或感兴趣都不自动生成评价。
3. **个人画像**综合当前有效作品报告和明确评价，独立版本化保存，并经显式启用才参与搜索/排序。普通统计画像重算不覆盖它。

手动分析只处理明确选择的一部作品。全库或新增作品策略是另一项默认关闭的授权，不能从一次手动任务推断已获全库外发许可。完整多画像、偏好 SSE、跨次推荐计划 CRUD 不在当前范围；写作只在 ai-writing。

## 冻结来源与全文覆盖

预览通过小说/系列 ID 读取本地归档，不接受任意路径、SQL 或客户端正文。清单包含章节 ID、顺序及来源、正文 hash、Unicode code point 长度、UTF-8 大小、缺失/空白状态、远端期望数量和出版状态。

正文 hash 对准确的 `text_raw` 计算，不再次归一化或默默裁剪。旧 hash 不一致时拒绝分析。没有可靠章序时由用户确认本次排列；不能混入其他作品或删掉不想分析的章节。空正文不能算完整，完全没有非空正文不能开始。

归档输入覆盖、原作是否完结/齐全、模型解释是否可靠是三种指标。远端数量与本地数量相等不等于完整原作；未知/连载/缺章须单独确认。预览不调用 Provider，开始时再次核对 fingerprint、配置和预算，冲突需重新预览。

冻结清单不复制整部正文到新表。执行原文单元时读取实际所需内容，核对清单版本；Provider 调用不得持有数据库事务。单元发布和最终发布继续验证 owner、清单、源 hash 与失效标记。

正文变化/删除、已选章节移出系列使运行失效；同 hash 元数据刷新不误作改文。创建后新增系列章节不偷偷纳入旧清单，可完成原输入但标记 archive_outdated。恢复只复用同一父任务、匹配版本的已验证检查点。

## 规划与证据

执行策略为整部优先，仅容量不够时分章/块，再有界分层汇总。缺 Key、禁用 Agent、无兼容候选不借分块掩盖。实际调用失败后不自动更换粒度或扩预算。汇总读过的是已验证产物，不能宣称重新阅读了全部原文。

正文块和产物均有大小/数量限制。覆盖以实际单元完成为准，不能把短样本分析标为全本完成。汇总结论必须关联已确认的输入来源，不允许捏造章号、证据或未分析的情节。

短引文的定位由服务端校验，偏移是 Unicode code point；浏览器转换 UTF-16 后定位，不能混用。报告、结论和 evidence ID 绑定具体版本；源过期时提供明确提示，不在新正文上伪造旧证据位置。

逐条结论反馈只改变该结论的使用资格，保留模型原始输出。标记不可靠与恢复都必须版本化，并使依赖画像重新验证；不得把“恢复使用”理解成用户保证结论真实。精确字段和完成状态以当前 API 与 STATUS 为准。

## 父预算与生命周期

用户必须显式确认整部请求数、计划 token 和活跃秒。范围分别为 1–512、1–100000000、30–14400。每次物理发送前按当前候选估算预留，网络计数和父预算同事务；未知结果保守计账，不能以异常退款后自动重复付费。

每子调用仍受 16 候选、32 请求、30 分钟限制。单元检查点不清预算；提额需要原版本和显式确认。正常停止只结算一次活跃时间片，崩溃或失去授权保守扣除未结算片。

任务使用共享单槽，与同步任务按已有优先级协调。取消/暂停/最终保存互斥；重启不重播付费调用。通用 AI continue 不代替作品 `/resume`；配置或源变化需要新任务。

## 个人画像与推荐依赖

有效来源要求报告完整覆盖本次输入、汇总成功、未过期/删除，并具有明确评价。系列评价优先于章节评价，避免同一系列重复计算。画像最多 2000 个反馈、16 MiB 序列化输入，超限拒绝，不静默抽样。

反馈、报告和结论使用资格参与来源身份。任务预览、发送前和发布前核对来源；用户撤回评价、改文、删报告或否定结论后，旧画像不得继续作为当前有效推荐依据。模型引用必须来自确认输入，伪造标签、极性、作品或证据要拒绝。

心跳读取有限反馈/报告身份行和单调报告 revision，不加载报告 JSON 或冻结的 sources_json；预览完整验证后保存来源 revision。报告状态或内容恢复也不回到旧 revision。迁移只为精确指纹仍匹配的已有画像补 revision，不能批量宣布旧画像有效。完整系列目录重排更新分析来源版本；本次归档章序仍需明确确认，不能把观测顺序当作已经验证完整原作。

画像独立保存、可显式启用和删除；首次启用只补最小默认统计画像。确定性规则消费有效画像和反馈生成搜索词、评分与理由，不把模型自由文本直接当排序代码，也不自动收藏/点赞。

## 全库与新增作品策略

全库扫描按系列与独立单篇去重，复用当前有效报告；持久记录已观察/尝试的来源身份，避免重启、删除已观察报告或相同 hash 刷新再次自动付费。实际新正文可形成新目标。

每部作品完整预算与批次/策略预占同事务。策略总请求、token、活跃秒与作品数跨批次累计，停用/重启/配置保存不清零；子预算提额也受总授权限制。首次新增模式记录范围基线，暂停和提额保留基线。

批次 completed 仅表示发现结束，子作品报告状态独立。自动策略关闭时不再创建新任务；已取得最终保存许可的结果可完成，不能伪造已取消。相关 API 只返回必要进度，不泄露正文和画像。

## 隐私与验证

通用 AI 调用保持 `metadata_only`。报告、证据和画像遵守 Dashboard 认证、CSRF、no-store，正文按文本节点显示，证据默认折叠；不进入普通日志、URL、localStorage、公开救援或 FTS。删除会撤权并清理敏感产物，迟到任务不得复活；不承诺备份/WAL 物理抹除。

验证覆盖全文与汇总路径、严格 JSON/重复键/非有限数、证据偏移、预算并发、取消/发布竞争、源变化、检查点、反馈失效、全库去重、浏览器迟到响应。离线 fake Provider 验证协议，真实解释质量、账单和手机体验需要独立验收。
