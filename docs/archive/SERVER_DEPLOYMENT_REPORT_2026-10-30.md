## 切换方法

1. 核对候选 SHA / tree、生产 tracked 状态、48 个新增路径无覆盖冲突，以及任务 / 模型同步无活跃操作。
2. 临时阻止外部变更请求，停止服务并确认没有进程持有数据库后制作最终备份。
3. 仅 fast-forward 更新代码；没有运行现有更新脚本中的强制重置或递归清理路径，保留原有未跟踪配置备份。
4. 仅增加可信代理、可信跳数与 Secure Cookie 三个指定配置值；保留原口令、加密密钥及用户 YAML 内容，将 `.env` / YAML 权限设为 `0600`。
5. 在真实库执行迁移和目录重建；检查本次 DDL 涉及的 `novels`、`series`、`recommendation_items`、`recommendation_seen` 及索引，另核验全局 FK、FTS 对齐和权威记录数。这里是范围明确的现场检查，完整库扫描已在副本完成。
6. 先以 `start_scheduler=False` 临时入口验收，随后移除覆盖、恢复正常 CLI。开始允许调度写入后，不再自动恢复旧快照；若激活失败，保留新数据库并退回受限实例等待诊断。
7. 验收通过后移除外部写入限制，再验证公网 HTTPS 登录及正常调度。受保护切换流程耗时约 2 分 10 秒；这不是前置测试 / 副本演练耗时。
